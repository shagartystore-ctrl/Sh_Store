# Sh_Store — زيتونة

واجهة متجر عربية RTL لبيع زيت الزيتون، مبنية بملفات HTML/CSS/JavaScript خفيفة.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## الموجود حاليًا

النسخة الحالية تحتوي على صفحة افتتاحية تسويقية، كتالوج منتجات مع فلترة، سلة مشتريات جانبية وحساب إجمالي، تصميم متجاوب للموبايل، وأقسام للجودة وقصة العلامة والاشتراك.

زر «إتمام الطلب» تجريبي حاليًا ويحتاج قرارًا لاحقًا بشأن واتساب أو بوابة دفع/خادم.
