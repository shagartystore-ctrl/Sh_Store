# Sh_Store — شجرتي

متجر عربي RTL لبيع زيت زيتون اكسترا ممتاز، مبني بملفات HTML/CSS/JavaScript خفيفة، مع Cloudflare Worker وD1 لإدارة المنتجات والطلبات.

## التشغيل المحلي

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`، ولوحة الإدارة من `http://localhost:4173/admin.html`.

## الخدمات

- Worker API: `https://shagarty-store-api.youssefzeweil1.workers.dev`
- قاعدة البيانات: Cloudflare D1 باسم `shagarty_store`.
- المنتج النشط: زيت زيتون اكسترا ممتاز بسعر 350 ج.م.
- الشحن: 80 ج.م ثابتة، والإجمالي الافتراضي للعبوة 430 ج.م.
- الدفع: الدفع عند الاستلام أو التحويل إلى Vodafone Cash على الرقم `01014761698`.
- عند اختيار Vodafone Cash، يرفع العميل صورة الوصل؛ تضغط الواجهة الصورة لتناسب الطلب، وتحفظها مع الطلب لتظهر داخل لوحة الأدمن.
- الطلبات الناجحة تفتح WhatsApp على الرقم `01014761698` برسالة برقم الطلب والإجمالي وطريقة الدفع.

## لوحة الإدارة

افتح `admin.html` وأدخل رمز الأدمن. الرمز محفوظ داخل Cloudflare Worker Secret باسم `ADMIN_TOKEN`، ولا يوجد داخل GitHub أو ملفات الواجهة. تعرض اللوحة بيانات العميل والعنوان وطريقة الدفع ورسوم الشحن وصورة إيصال Vodafone Cash.

مجلد Cloudinary `shagarty/products` جاهز لاستضافة صور المنتجات، وحقل رابط الصورة متاح في لوحة الإدارة.
