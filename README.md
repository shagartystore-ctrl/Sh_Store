# Sh_Store — شجرتي

متجر عربي RTL لبيع زيت زيتون اكسترا ممتاز، مبني بملفات HTML/CSS/JavaScript خفيفة، مع Cloudflare Worker وD1 لإدارة المنتجات والطلبات.

## التشغيل المحلي

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`، ولوحة الإدارة من `http://localhost:4173/admin.html`.

## الخدمات

- Worker API: `https://shagarty-store-api.youssefzeweil1.workers.dev`
- قاعدة البيانات: Cloudflare D1 باسم `shagarty_store`.
- المنتج النشط: زيت زيتون اكسترا ممتاز بسعر 350 ج.م.
- الشحن يبدأ من 80 ج.م ويُدار من لوحة الأدمن عبر إعدادات D1؛ تغيير القيمة يطبق على الطلبات الجديدة فقط.
- الدفع: الدفع عند الاستلام أو Vodafone Cash على الرقم `01014761698`.
- إيصالات التحويل تظهر داخل لوحة الأدمن.
- الصور والفيديوهات التي يرفعها الأدمن تذهب مباشرة إلى Cloudinary باستخدام Upload Preset باسم `shagarty_products` داخل مجلد منتجات شجرتي.

## لوحة الإدارة

أدخل رمز الأدمن في `admin.html`. تعرض اللوحة إجمالي المبيعات، عدد الطلبات، متوسط قيمة الطلب، الطلبات المفتوحة، مبيعات الطلبات المسلّمة، ومبيعات آخر 7 و30 يومًا. كما يمكن تعديل قيمة الشحن من بطاقة «إدارة الشحن». من نموذج إضافة المنتج يمكنك اختيار صورة أو فيديو من الجهاز، وسيتم رفعه إلى Cloudinary ثم حفظ رابطه مع المنتج. المنتجات تعرض الوسيط في جدول الأدمن ويمكن حذفها بزر «حذف المنتج»؛ الحذف يخفي المنتج من المتجر ويحافظ على بيانات الطلبات السابقة.

## API الإعدادات

- `GET /api/config`: إعدادات عامة آمنة، ومنها قيمة الشحن.
- `GET /api/admin/stats`: إحصائيات المبيعات وحالات الطلبات وأفضل المنتجات.
- `GET/PATCH /api/admin/settings`: قراءة وتعديل إعدادات الأدمن.

## بيانات العميل

يحفظ المتجر الاسم ورقم الهاتف والعنوان تلقائيًا في متصفح العميل باستخدام `localStorage`، وتظهر البيانات مرة أخرى عند فتح نموذج طلب جديد من نفس الجهاز والمتصفح.
